# Трекер прочитанных книг

Консольное приложение для учёта прочитанных книг с модульной архитектурой.

## Функциональность
- Добавление книги (автор, название, оценка 1-5, дата)
- Просмотр всех книг
- Средняя оценка
- Статистика по авторам
- Удаление книги
- Проверка дубликатов

## Структура
- main.py — интерфейс и меню
- storage.py — работа с JSON-файлом
- stats.py — расчёт статистики
- models.py — класс Book

## Запуск
python main.py
